★ V6 CHANGES — BASED ON REQUIREMENTS DOC
UPDATEDEVENTS
event_type updated to match 3 real event formats
Changed from generic hackathon|workshop|demo to the actual platform event types: build_challenge, maker_meetup, tech_tuesday. Added is_recurring for Tech Tuesdays and recap_url for session archives.
ALTER TABLE event ALTER COLUMN event_type TYPE VARCHAR(20); ALTER TABLE event ADD CONSTRAINT chk_event_type CHECK ( event_type IN ('build_challenge','maker_meetup','tech_tuesday') ); ALTER TABLE event ADD COLUMN is_recurring BOOLEAN DEFAULT false; ALTER TABLE event ADD COLUMN recap_url TEXT;
UPDATEDPROJECT
project table extended for Project Proposal Framework
Added one_line_summary, github_url, and duration_estimate from the Project Proposal Framework template in the requirements doc.
ALTER TABLE project ADD COLUMN one_line_summary VARCHAR(255); ALTER TABLE project ADD COLUMN github_url TEXT; ALTER TABLE project ADD COLUMN duration_estimate VARCHAR(50); -- '1 week / 1 month / ongoing'
NEWEVENTS
event_team + event_team_member — team registration for Build Challenges
Build Challenges require team registration. A team belongs to a single build_challenge event. Members join with a role of lead or member.
CREATE TABLE event_team ( id SERIAL PRIMARY KEY, event_id INT NOT NULL REFERENCES event(id) ON DELETE CASCADE, team_name VARCHAR(100) NOT NULL, created_by INT NOT NULL REFERENCES app_user(id), created_at TIMESTAMPTZ DEFAULT NOW() ); CREATE TABLE event_team_member ( id SERIAL PRIMARY KEY, team_id INT NOT NULL REFERENCES event_team(id) ON DELETE CASCADE, user_id INT NOT NULL REFERENCES app_user(id), role VARCHAR(20) DEFAULT 'member' CHECK (role IN ('lead','member')), joined_at TIMESTAMPTZ DEFAULT NOW(), UNIQUE(team_id, user_id) );
NEWEVENTS
showcase_slot — slot booking for Maker Meetups
Maker Meetups need a slot-booking workflow: presenters apply for a demo or speaker slot, admin approves. Maps to the "Book Showcase Slot" flow from the requirements.
CREATE TABLE showcase_slot ( id SERIAL PRIMARY KEY, event_id INT NOT NULL REFERENCES event(id) ON DELETE CASCADE, user_id INT NOT NULL REFERENCES app_user(id), title VARCHAR(200) NOT NULL, slot_type VARCHAR(20) CHECK (slot_type IN ('speaker','demo','product')), status VARCHAR(20) DEFAULT 'pending' CHECK (status IN ('pending','approved','rejected')), project_id INT REFERENCES project(id), notes TEXT, booked_at TIMESTAMPTZ DEFAULT NOW() );
NEWEVENTS
event_submission — project submission portal for Build Challenges
Build Challenges need a submission portal. A team (or individual) submits a project. Admins/mentors can mark a winner.
CREATE TABLE event_submission ( id SERIAL PRIMARY KEY, event_id INT NOT NULL REFERENCES event(id) ON DELETE CASCADE, project_id INT NOT NULL REFERENCES project(id), team_id INT REFERENCES event_team(id), submitted_by INT NOT NULL REFERENCES app_user(id), submitted_at TIMESTAMPTZ DEFAULT NOW(), status VARCHAR(20) DEFAULT 'submitted' CHECK (status IN ('submitted','reviewed','winner','disqualified')) );
NEWTAGS
tag + entity_tag — polymorphic tagging for profiles, projects, challenges
Requirements list Tags on Maker profiles and projects. Polymorphic design: one tag can apply to projects, challenges, or maker profiles. Admin can create tags; makers apply them.
CREATE TABLE tag ( id SERIAL PRIMARY KEY, name VARCHAR(80) UNIQUE NOT NULL, slug VARCHAR(80) UNIQUE NOT NULL, category VARCHAR(30) CHECK (category IN ('domain','skill','tool','theme')) ); CREATE TABLE entity_tag ( id SERIAL PRIMARY KEY, target_type VARCHAR(30) NOT NULL CHECK (target_type IN ('project','challenge','maker_profile')), target_id INT NOT NULL, tag_id INT NOT NULL REFERENCES tag(id) ON DELETE CASCADE, tagged_by INT NOT NULL REFERENCES app_user(id), UNIQUE(target_type, target_id, tag_id) ); CREATE INDEX idx_entity_tag_target ON entity_tag(target_type, target_id);
